# 🎮 Video Game Sales Prediction

## 📌 Project Overview

The **Video Game Sales Prediction** project is a Machine Learning-based data analysis and prediction system designed to analyze historical video game sales data and predict sales performance.

The project focuses on exploring the factors that influence video game sales across different platforms, genres, publishers, and regions. By applying data preprocessing, Exploratory Data Analysis (EDA), and predictive modeling techniques, this project aims to identify sales patterns, understand market trends, and develop a data-driven approach to video game sales prediction.

## 🎯 Project Objectives

- Analyze historical video game sales data.
- Understand sales trends across different gaming platforms and genres.
- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Identify important factors influencing video game sales.
- Apply Machine Learning techniques for sales prediction.
- Evaluate predictive model performance.

## 🛠️ Technologies Used

## 📂 Dataset

The project uses the `vgsales.csv` dataset, which contains historical video game sales information.

The dataset is used to explore sales performance and analyze patterns across different categories of video games.

## ⚙️ Project Workflow

1. Data Collection and Loading
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis
4. Data Visualization
5. Feature Selection
6. Machine Learning Model Development
7. Model Evaluation
8. Video Game Sales Prediction

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/babusonamondal686-ui/Video_Game_Sales_Prediction.git
   ```

2. Install the required Python libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn
   ```

3. Open `Video_Game_Sales_Prediction.ipynb` in Google Colab or Jupyter Notebook.

4. Make sure `vgsales.csv` is available in the correct directory.

5. Run all notebook cells to execute the project.
